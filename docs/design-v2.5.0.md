# v2.5.0 每日总结设计

## 目标与界面
在侧栏添加「每日总结」，与每日计划、月度回顾、专注时钟并列。左侧为可搜索的历史列表，按日期倒序；右侧为当前日期的 Markdown 编辑器与安全的只读预览。日期选择器允许补写和修改往日总结，「今天」快速返回；每日计划也提供当前所选日期的总结入口。历史列表展示日期和首行摘要，空列表有明确引导。

## 文件规则
默认路径为程序旁 data/document/YYYY-MM-DD.md，UTF-8，无数据库及私有包装格式，一日一文件。使用用户指定数据位置时保存为该位置/document。只识别严格有效日期命名的 .md 文件。查看某一天不创建目录或空文件；新文档仅有空白也不创建文件。已存在文档清空后可保存为空文件，删除必须主动确认。跨午夜保持正在编辑的日期，避免写到另一日。

## 编辑与保存
支持标准 Markdown 文本、可选总结提纲、编辑/预览切换和 Ctrl+S。停止输入一秒后自动保存，切换日期、切换页面、收起到托盘、退出和迁移位置前保存。使用 QSaveFile 原子替换；保存前比较加载时的文件内容，检测外部改动，不覆盖外部版本。失败保留编辑器内容，阻止会丢失修改的导航与退出，提供重试及另存副本。界面持续显示待保存、已保存、未创建或失败状态。预览禁用外链跳转与本地/远程图片资源加载，不发网络请求。

## 历史与删除
日期选择、历史列表及日期/正文搜索支持回看。历史文件可继续编辑；打开文档文件夹可用其他编辑器查看。明确的「重新读取」操作经确认后丢弃未保存编辑，载入外部新版本。删除当前总结需确认，移动到 document/.trash 中带唯一标识的 .md 文件，可手动恢复；不永久删除。已删除记录不出现在历史列表。

## 集成与发布
迁移数据位置时包含 document 及其回收目录，遇到同名不同内容不覆盖。现有 JSON 计划备份仅含计划，文档说明单独复制 document 备份总结。打包检查继续禁止任何用户数据（包括总结）进入发布包。版本统一为 2.5.0，一次完整实现后更新版本说明并提交本地 Git；未经请求不推送或发布 GitHub。
